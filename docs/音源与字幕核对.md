# 音源与字幕核对

- 音源：`input/song.flac`（自备），214.27 秒，48 kHz。元数据为 2025 年 LAUNCH-BOX 发行版（Tidal 480548638）。
- 字幕：`input/lyrics_karaoke.ass`（自备），54 行，逐字计时来自网易云 YRC 526473115。
- 核对方法：用 Demucs（htdemucs）从指定音源中分离人声，拿人声的起音和响度去比对每个字、每一行的时间。同目录的伴奏版和指定音源不是同一版母带（波形相关系数只有 0.2），不能直接相减得到人声，所以没有用它。
- 工具：`tools/verify_ass.py`、`tools/ass_offset.py`。结果数据在 `work/audio/`。

## 片中歌词时间的唯一来源（2026-11-19 补）

- 片中出现的每个字，什么时候出，一律从 `work/audio/lyrics_timed.json` 取。这份表由 `python tools/lyric_times.py build` 生成：逐字 ASS 统一前移 0.10 秒，再写入 `work/audio/lyric_fixes.json` 里人声实测的修正。场景用 `ltimes=1&lwin=起-止`（秒）从表里读，不在 query 里手填时间。
- 起因：05 试做片段的「もうどうだっていいや」是手填时间，把最后「や」拖长时的转音（3:00.40 之后音高从 G5 到 A5、F#5 的变化）当成了「い」「い」「や」三次开口，后三个字一个比一个晚，最晚晚了 0.58 秒。
- 规则：同一个元音拖长时的音高变化不是新字。用起音检测对时，必须同时对照逐字歌词和音高曲线确认是不是换了字。
