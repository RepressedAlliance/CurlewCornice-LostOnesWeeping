# 六个特殊拍点的实测核对（2026-11-20）

全片分镜“开工前要锁定的”第二条：用实测核实 k0、k36–40、k132、k324、k420、k520 前后的能量，按实测排事件。结论先写在前面，逐拍数据在后面。

## 先说怎么读

- 本文的 k 一律是**拍号**（和 `全片分镜.md`、`拍号帧对照.md` 相同）：拍点 = 0.318 + k × 0.37037 秒，帧 = round(秒 × 30)。k38.5 是第 38 拍后的半拍，k38.25 是十六分音符。
- `work/audio/accents.json` 的 `half` 数组里 `k` 是**半拍序号**，等于拍号 × 2（拍号 36 = half 72）。它的 `t` 用的是 0.354 的理论网格，峰值实测普遍早约 36 毫秒，正好落在 0.318 网格上，所以两边是同一批拍点。
- **accents.json 的 `acc` 到 1.0 就封顶了**（按全曲第 98 百分位归一化），全曲 1155 个半拍里有 48 个是 1.0，其中 34 个在正拍上。所以“acc = 1.0”只说明这一下不弱，**不能说明它特别**。k36、k132、k420 被当成特殊拍，部分原因就是这个封顶。
- 因此本文另外从伴奏分轨（`no_vocals.wav`）按十六分音符量了三样东西：全频段响度、低频（30–160 Hz，底鼓和贝斯）响度、全频段起音强度（以全曲第 99 百分位为 1），再加人声分轨的响度。响度单位是 dB，0 是全曲常态的满响，−20 dB 算明显空了，−45 dB 以下就是没声音。

## 数据怎么来的

- 伴奏和人声分轨：`work/audio/sep/htdemucs/1. Neru - Lost One's Weeping/`。
- 每个十六分音符取拍点前 20 毫秒到下一个十六分音符前 20 毫秒的平均功率（鼓点实测都提前约 36 毫秒，这样窗口能完整包住打击），各频段分别以全曲第 95 百分位为 0 dB；起音强度是 librosa onset strength 在窗口内的最大值，以全曲第 99 百分位为 1。
- 和 accents.json 的半拍数据对照过，凡是两边都覆盖的半拍，结论一致；不同之处只在于 accents.json 的 `acc` 封顶，看不出 k38.5 这类拍比普通正拍强一个数量级。
