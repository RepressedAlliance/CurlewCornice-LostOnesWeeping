## 2. 作者意图

**观众该看到、感到的：** 片头那段音型又响起来的第一拍，画面切回第一帧：同一个画框，她的眼睛在同一个位置，身后是同一面涂黑的格子墙。只是这一次，她的脸前面没有举着卡，领口那里也没有颈绳垂进去，什么都没有。她抬起眼睛看着我们，一动不动。音型走到第一遍的最后那一下，她闭上眼，镜头往前一顶，和片头那一顶一模一样；第二遍的第一下，开头砸下「読み取れません」的那一下，什么也没有落下来：她睁开眼，还是看着我们，眉头和眼皮松了下来。然后画面一下变白。不是胜利，是松手以后的平静，「もうどうだっていいや」的另一面。

**看点（静音的人为什么看到最后一秒）：**
1. 首尾闭环：结尾的画面和第一帧同一个画框，差的正好是那张卡、那双手和那根颈绳，看过开头的人一眼认得出；循环重看也成立。
2. 全段最重的一下（k564）上，“该印字的地方没有印”，换成她的表情。
3. 最后一个变化压在最后 3 秒，提前关掉就看不到。

**验收标准（先全部算未通过）：**
1. 把第 0 帧和第 6187 帧并排，看过开头的人盲看，答得出“同一个画面，只是没有卡、没有绳了”；两帧的眼睛位置重合。
2. k564 那一拍静音看也看得出“她的表情变了”，手机 390×220 上也看得出（变化在眉毛和眼皮这一级，不只是嘴角）。
3. 表情盲比后选最克制的：不露齿，不哭，眼睛不笑弯；评审不会用“开心”“得救”来形容。
4. 全段没有任何点阵字、手写字、印章。
5. k556 的切看得出是“她抬起眼睛”，不像跳了一下。
6. 位图放大不超过 00 段第 0 帧的倍率（约 1.09，一顶时约 1.11）。
7. k572 那一帧一刀切纸白，不淡出。

## 3. 关键画面的两种设计

关键画面是“开头那一下又来了，却什么也没有落下”（k563–k572）。k556–k563 两种相同。两种都做成带音乐的小样，和 15 段 S7 连起来盲比后定；表情 `r16_free_a`、`_b` 在两种里一起盲比。

### 甲：镜像特写，k564 只换神情（推荐）

k556 切进第 0 帧的构图，她直视，没有表情，静止。k563 闭眼，镜头往前顶 2%，k563.5 回原位。k564 本该砸字的那一下，什么也不印，她睁开眼，还是看着我们，眉头和眼皮松下来。格子墙一直是黑的。停到 k572，一刀切纸白。

### 乙：同上，k564 身后的格子墙褪回纸白

k564 她睁眼的同一拍，身后整面黑格子墙两帧内从右往左褪回纸白的格子（碧青印刷线还在，铅笔黑没了），和 00 段 k7 从左往右涂黑的方向正好相反：这一下不印了，格子也空了。之后她在纸白的格子墙前停到 k572，再一刀切成一整片纸白（格子线也没了）。

### 推荐甲，理由

- 甲最克制：唯一的变化是她的脸，“松手”只落在一个人身上，不给世界下结论，最守「もうどうだっていいや」的撒手语气。
- 乙是整画面的明暗变化，手机上最醒目，也把 00 段 k7 的涂黑完整地倒过来；但“世界变白了”很容易被读成“一切都好了”，正是改定 10 要防的大团圆。乙的 k572 切白只剩格子线消失，最后一刀变弱。
- 什么时候改选乙：盲看的人在甲里看不出 k564 有变化，而且乙在“这是好结局吗”的问题上大多数答“不是”。
