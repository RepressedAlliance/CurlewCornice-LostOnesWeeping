## 2. 作者意图

**观众该看到、感到的：** 从负片的水沟一下切回检票口：她还站在 03 那扇关着的门后面，低头看着自己那张读不出来的卡，头顶黑墙上一个字一个字擦出她的问题「何時になりゃ大人になれますか」。镜头转到她身边那些被机器读得清清楚楚的大人：一拍，离她最近的大人卡上砸下开头那一枚「読み取れません」，门板在他腰前啪地合上；再一拍，外面一圈；再一拍，整排七条通道的门全关了，每张卡上都是那一道黑条，她站在正中间。原来大人也读不出来。她左右看，想找个人问，没有一个人抬头，钟照常走。墙上她问过的话一下子全被涂回黑色；镜头一拍一拍逼近，她攥紧胸前的卡，一拽，后颈的扣子啪地弹开，绳从肩上滑下来，她把卡连绳甩向我们；身边的大人胸前的卡同时一齐掉下去。卡迎面飞来，越来越大，上面是她自己写的「もうどうだっていいや」，贴满整个画面。

**看点（静音的人为什么停下来）：**
1. 规则在最后一次副歌整个翻过来：前奏教过的那一枚章，三拍里由近到远砸满所有人，门板一条接一条关上，最后全景里一条横贯画面的黑带，中间是她；看得懂、有快感，不用认字（门在大人面前关上，和 03 关住她是同一个画面）。
2. 她找人问的那一句是全段唯一的“没人回应”：中景里所有人低着头、只有钟在走，墙上写满她的问题；下一拍这些字被一齐涂黑，接着镜头四档逼近。
3. 全片的招牌动作：胸上景里一拽一甩，卡迎面冲来贴满镜头，这一帧能当封面。

**验收标准（先全部算未通过，看过带音乐的渲染才改）：**
1. k464 那一拍在手机尺寸下盲看，答得出“那个大人的卡被盖了和她一样的章、门关上了”；k468 答得出“所有门都关了”。
2. 她左右看的两张，在手机上看得出“在找人”，不像随便转头。
3. 扯断时盲看的人不会说出“勒”“吊”“脖子”之类的词；手机 390×220 下答得出“她把挂卡的绳子扯掉了，把卡扔了过来”。
4. 甩卡的手臂长度对人设量过，不短不扁；卡离手的位置和手对得上。
5. 甩卡以后画面里只有一个大运动（飞来的卡）；落卡竖直、同一拍、不翻转，不像随机特效。
6. 卡贴满镜头那一帧单独看是一张海报：机器的「読み取れません」和她的铅笔字同时读得到。
7. 大厅立面、石墨墙和 2D 的她、路人合成一体（同一套碧青印刷、同一种描线、白卡不发光），和 03、01 放在一起是同一部片子。
8. 和两段 demo 第 15 版并排比不未达标准。

## 3. 关键画面的两种设计

关键画面是句 53（k479–k488）的蓄力、扯断和甩卡。S1–S3 两种设计相同。两种都做成带音乐的小样，盲比后再定。

### 甲：四档逼近，胸上景一拽一甩，卡迎面贴满（推荐）

k479 墙上的字被涂黑，镜头从句 52 的中景每拍一档往她推（四档），k482 落在 03 最后一帧的胸上景，k482.5 半拍全静；k483 军鼓，她右手攥着卡往外一拽，后颈的安全扣弹开，绳从两肩滑落；k484 小节线，她把卡连绳朝画左前方甩出，镜头从这一拍起极缓地往后拉（1.3 倍，缓入缓出），卡始终正面朝我们、按 1/距离 的规律越飞越大；k485 近处的大人胸前的卡同一拍竖直落下；k488 卡贴满镜头，接 15 段。

### 乙：她把卡举到脸前，扯掉，然后松手

k479 切 2D 大特写，和 00 段第 0 帧同一个构图：她把卡举到鼻梁，只露眼睛。k483 右手往前一拽，绳从两肩滑落；k484 她张开手指，卡往下掉出画框，露出整张脸（00 段 k4 的动作反着用）；同一拍切七条通道的全景，近处的卡一齐落下。k488 切进 15 段时是全景，没有“贴满镜头”。

### 推荐甲，理由

- 甲是主动的一甩，卡冲着观众来，贴满镜头既是这首歌最后一句的爆发，又直接把 15 段打开（卡落开露出大厅），招牌动作和转场是同一个动作；乙是松手，更贴“撒手”二字，但力度弱一档，也少了转场。
- 甲的四档逼近接在“问题被涂黑”之后，把吼的那一句一拍一拍收紧，正是歌迷评审要的蓄力；乙的蓄力要靠切特写，节奏断一下。
- 乙用掉了 00 段第 0 帧的构图和“卡拿开露出脸”，16 段要和第 0 帧镜像的结尾就没有新东西了。
- 甲的风险是拽卡和甩卡两张图难画（手臂长度、方向、绳子走向）。小样里如果怎么画都不对，或者盲看的人看不出卡是她甩过来的，就改选乙，15 段开头相应改成全景。
