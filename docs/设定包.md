# 设定包

全片反复出现的人物、道具和场景元素各有一张定稿设定图，放在 `art/canon/`。之后每一张出图都以这里的设定图为第一参考（制作约定第五节“设定包先行”）；镜头图按机位、动作重新画，不直接把设定图贴进镜头。设定图要改，就在这里换文件并写明日期和原因，不在镜头里各改各的。

生成方法：提示词在 `art/design/prompts/_make_setpack.py`（`sp_*.txt`），任务 `art/design/jobs/setpack*.json`，候选原图在 `art/design/out/sp_*.png`。答题卡由代码画（`web/lib/card.js`），用 `node web/canon_cards.mjs` 重新导出。2026-11-20 建立；同日按两轮美术审查各修了一轮（见文末“2026-11-20 第三轮修正”“2026-11-20 第四轮修正”）。

后处理只做测量、裁切、缩放和延长，以及按固定网格由代码排机器的印字，不手工补画：`art/design/prompts/_setpack_fixups.py`（第三轮：大橡皮裁画幅、芯加长、调 Les Paul 几何）、`art/design/prompts/_setpack_fixups4.py`（第四轮：大橡皮和读卡机的橡皮印字、Les Paul 琴颈）、`tools/lespaul_refit.py`、`tools/lespaul_neckfit.py`、`tools/lespaul_measure.py`（按审查的量法量品位、琴颈宽和侧面厚度）、`tools/eraser_print.py`（橡皮纸套的点阵字和定时方块）、`tools/alpha_clean.py`（清透明通道的淡残渍）；`art/design/prompts/_setpack_install.py` 把选中的图清好透明通道放进 `art/canon/`，旧图移到 `archive/canon_replaced/`。几何参考线图由 `art/design/prompts/_setpack_guides.py`（Les Paul、闸机）和 `_setpack_guides4.py`（大橡皮、读卡机、握笔的手）生成（`art/design/board/guide_*.png`）：有尺寸或机构的设定图都先画一张量好的灰线图，跟提示词一起给 Codex，只用文字写尺寸会跑偏。`tools/town_lineup.py` 重排 `town/_lineup_same_scale.png`。

## 两种画法，不混用

- **她的画法（全彩）**：人设图那一手：干净的动画设定稿，深灰描线，每种材质一档硬阴影，不用渐变。用在她本人、Les Paul、琴包、芯ホルダー。她是全片唯一全彩，Les Paul 的金色面板（和金色旋钮）是唯一的暖色。
- **小城的画法（碧青单色印刷）**：纸白 #F5F3ED 上只有碧青 #218EA3 一种墨：描线，阴影和深色衣物用规则的圆网点，黑发、深色西装用实碧青或密网点。铅笔黑 #2A2A2F 只出现在卡上涂黑的格子、读卡机的印字这类“机器读得到的黑”。用在路人、读卡机、大橡皮、储物柜、闸机、自己紹介カード、原稿用纸的格子。
- 两种画法都不用红色（`tools/red_scan.py art/canon` 和 `art/canon/town` 已扫，0 处）。
