# 经验与检查清单

本片制作中遇到的每个问题都当作“一类问题”处理：先查成因，再在全片找同类，改掉成因。下表按“问题类型 → 成因 → 检查方法”整理，每段交付前、每轮全片审查时逐条对照；“检查方法”一栏就是做每一段时的自检项。

## 审看中发现的问题

| 问题类型 | 成因 | 检查方法（全片同类一起查） |
|---|---|---|
| 人物图不合用时，用代码裁切、拼接去凑 | 人物图不合用时，用代码裁切、拼接、挪像素去凑，没有让 Codex 带参考图整张重画 | 每张人物图都是 Codex 整张画出来的，代码只做对齐、摆放和动画；凡是要改人物本身的，一律重画 |
| 特写裁掉了人物的头 | 特写的裁切由代码决定，用了一张不是为特写画的图 | 每个特写、近景都要看到这一镜该看到的东西：人物完整，裁边只能是画框裁的；为特写单独出图 |
| 3D 镜头歪斜、杂乱，为做 3D 而做 3D | 为了满足“要有 3D”而做 3D；镜头转斜、广角透视、卡片乱摆；把平面人物立进强透视里，是我们的短处 | 所有 3D 镜头：不转斜，竖线竖直，中长焦，卡阵整齐；人物只配和画法一致的水平机位；做不好就用 2D |
| 先做静帧定方向，动起来才发现不成立 | 先做静帧定方向，动起来以后才发现节奏和演出不成立 | 每个设计都按带音乐的视频来判断，直接做成视频再改到达标 |
| 版式没有设计、复用旧页面 | 旧的试卷页代码直接拿来用；字号和位置写死，没先量 | 每块字先量再放，程序检查重叠和出框；弃用的素材和代码不再拿来凑 |
| 歌词像一条独立字幕，没有融进画面 | 把歌词做成一条字幕带，和画面无关 | 每一句歌词都是画面里的东西：她的铅笔字、读卡机的点阵字、纸上的印刷字；不做字幕条，只用日文 |
| 画面里出现来历不明的半截笔迹 | 画面里出现了没有来由、没设计过的笔迹 | 画面上每一笔、每个记号都要有来处和意义，按笔画路径和节拍出现 |
| 切镜、换张没有统一落在节拍上 | 切点、换张、镜头起止没有统一的节拍规则 | 所有画面事件登记时间，BEAT AUDIT 自动检查是否落在实测拍点（半拍只给小动作） |
| 人物换张过密，像逐帧动画 | 一句里换好几个姿势，像在做逐帧动画 | 人物靠关键原画加镜头、落笔、回弹做动态；换张要有意思上的理由 |
| 画面整体比音乐早 | 实测鼓点本身就是起音，又让画面提前了一帧 | 画面压在实测鼓点上，歌词按实际开口出现，不再加提前量 |
| 歌词比演唱晚 1–2 帧才读得出 | 把“歌词在开口时出现”做成了“开口后才开始出字”：共用的出字曲线从开口后的第一帧起按 1/3、2/3、1 淡入或扫入（帧取整再晚 0–1 帧），全片 632 个字平均在开口后 46 毫秒、多数 1–2 帧才读得出，这正在人能察觉“画晚于声”的界线上（约 45 毫秒）；几段页面自己的出字动画更晚：05 卡片飞走 3–4 帧，08a「その心」等黑色漫到才显字（晚 0.45–0.7 秒），08b「おいどうすんだよ」写字扫入（最多晚 0.21 秒），12 句 40 写字扫入 0.16 秒，13 点阵逐字扫入 3 帧。数据本身（人声分轨核对，差 10–20 毫秒）和合成的音画对齐（成片、手机版、HLS 实测 0 样本偏移）都没有问题 | 每个唱出来的字都按“开口那一帧已读得出”检查：可以提前 1–2 帧开始出现，淡入、扫入、写字、刷出、等别的东西来了再显字，都要在开口那一帧之前做完或缩到 2 帧内；页面自己判断出字时用 `print.js` 的 `sungShown`/`sungBuild`/`sungSweep`，不写 `tt >= t`；`lyrics.js` 的 `lyricAudit` 列出读晚的字；`assemble_film.py` 每次合成交叉相关核对声画同步 |
| 差分换张太突然 | 差分只停两拍（0.7 秒），中间张只放两帧 | 见下一行 |
| 差分和中间张停留太短 | 我把 ココロ 时定的“至少两拍”照搬过来，只做到下限，检查也只查下限；中间张当成一闪而过的两帧 | 每张差分停到能看清再换，一句里不硬塞几张；中间张停住、让人看得出是在动（一般半拍起）；HOLD AUDIT 列出每张的实际停留秒数，逐张看是否太短 |
| 没验证是否需要就批量生成中间张 | 没等看过效果就给每次换张都开了生成 | 先用现成的渲出来逐帧看，哪一处不连贯才给那一处补画 |
| 2D 画面里出现了红色（第一阶段定了全片不用红色） | 判定、警示顺手用了红色 | 全片不出现红色：判定是铅笔黑，纸面是碧青印刷；渲染后自动扫红色像素 |
| 儿时回忆用了本身不好看的蜡笔涂鸦 | 用了本身就不好看的形式表现“小时候” | 回忆、作文、作业这类画面用本身好看的形式（原稿用纸、整齐彩铅等） |
| 群众复用同一张人物线稿 | 图省事复用同一张图 | 群众每人不同的姿势、表情、体型；同一张人物图不在多个镜头里重复，复用要写理由 |
