# 『ロストワンの号哭』制作ガイド

## 構成と絵コンテ

冒頭で町の規則を見せます。胸に下げたマークシートの印を機械が読み、その人の情報として扱う。リンの分だけ「読み取れません」。無音でも追えるように、カードの状態、青緑の紙面を覆う黒鉛、規則を乱す金色のギターを全編に通しました。冒頭で彼女を向くのはカードで、終盤で振り向くのは人間です。

| 区間 | 物語と演出 |
|---|---|
| 00–02 | 画面に広がるカード、氏名欄に打たれる読み取り失敗の文字。列車が去り、音の切れ目で周囲のカードだけが振れる。 |
| 03 | 読み取り機が題名の前半を印字し、彼女が鉛筆で書き足す。カードをかざす動きと閉じる改札で町の仕組みを見せる。 |
| 04–05 | 彼女のカードの裏へ黒鉛がにじむ。金色のレスポールが現れ、ギターに合わせて成績表のカードが跳ね、点を連ねた文字の形に穴が開く。 |
| 06–07 | 結果票から自己紹介カードと部屋、カレンダーへ。将来の夢の欄は空のまま。 |
| 08a–08b | 試験用紙を舞台にする。消しゴムが黒い面を横切り、そろばんは答えを出し、ひもの図解は元に戻る。鉛筆が折れる。 |
| 09 | 防球ネットの奥にまで並ぶカード。列ごとに裏返り、書き込まれた黒が山の形を作る。ギターを持つ彼女へ切り替える。 |
| 10–11 | 夜の電車の窓に顔が映り、ギターケースはロッカーへ。夢の記入欄と消しゴムで、ほかの人物の書いたものにも触れる。 |
| 12 | 見覚えのある試験用紙が段階的に裂ける。隙間の奥で彼女が取り戻したギターを弾き、紙の帯が拍に合わせて落ちる。 |
| 13 | 全編で唯一のネガ調。机の明かりの下で昔の作文を広げ、誰が消しゴムを持っていたか見せる。 |
| 14–16 | 大人のカードにも読み取り失敗が印字される。彼女のカードが外れ、改札の紙が落ち、人が振り向き、ギターが読取機を打つ。冒頭と響き合う構図で閉じる。 |

18 区間のフレーム番号は [web/segments.json](../web/segments.json) が基準です。[絵コンテの原稿（中国語）](全片分镜.md) には初期案と試写後の改定もあります。

## 人物・カード・道具

リンの頭身、町の人々、読み取り機、ギター、ひもとカードを設定画でそろえます。[設定画](../art/canon/) と [プロンプト](../art/design/prompts/) を渡して一枚として描き、差分は同じ母版から変更の一点を指定します。体の向きはカメラの角度と合うようにし、連続した絵の輪郭、色、道具の位置を使用時の大きさで確かめます。

カードは横 3:2 の紙です。明るい紙の縁、マーク欄、クリップ穴、ひもを残します。「読み取れません」は氏名欄、03 から機械が印刷した題名を学籍番号欄、続きの鉛筆文字を偏差値欄に置きます。見出しを隠さず、題名の下の青緑だけを薄くして文字を立たせます。裏の黒鉛も記入枠内で広がり、紙の端を残します。スマートフォンの小さい画面で黒い端末に見えないための手掛かりです。[カードの実装](../web/lib/card.js)

絵ごとにペン、弦、ジャック、ひもの接点を測ります。[parts.js](../web/lib/parts.js) は人物画像と描画部品を同じ位置・縮尺で変換します。絵を切り替えるときに基準点も切り替え、切り替え前後を並べて見ます。芯だけがペンから離れたり、弦がギターから外れて見えたりする問題はこの工程で直しました。

## 2D・3D と印刷

- 主体は Canvas の 2D。[改札](../web/scenes/segments/seg_03.js) は正面から見た立面のレイヤーで描きます。[防球ネットの場面](../web/scenes/segments/seg_09.js) では、厚みのある 3D カードの回転と照明を計算して Canvas に投影します。水平の長焦点で縦線と格子を読みやすくし、視点に合わせて人物の絵の大きさと位置を決めます。
- 青緑の専色、黒鉛、網点、版ずれが画面をそろえます。彼女と金色のギターがその中で際立ちます。赤は全編で使いませんでした。歌詞は用紙と表示盤に直接置きます。[印刷](../web/lib/print.js) · [色](../web/lib/palette.js)
- 縦に持った端末で読めるか確かめます。点を連ねた文字は発音と同時に読める大きさにし、縦組みは文字を測って人物との間隔を取ります。[組版](../web/lib/type.js)

## 拍と試写

実測のグリッドは `0.318 + k × 0.37037` 秒、約 162 BPM。[score.js](../web/lib/score.js) に拍と聞こえる細分の時刻を持たせます。カット、カメラの開始と停止、差分、打撃、印字を登録。全画面を揺らすのは節目に絞り、カードの裏返りや弦など画面内の動きで拍を見せます。歌詞は発音を含む最初のフレームで読める状態にします。

各区間をまず無音で見て、画面だけで見せ場が伝わるか確認します。その後に音と前後の区間をつないで、拍、表示時間、A→B→A の戻り、画像の拡大、色、裁ち端、静止、部品の接点を検査します。問題が出た箇所と同じ原因を全編から探します。制作側の確認後、別の評者が必須の修正と提案を出し、再び試写します。[レビュー用スクリプト](../work/workflows/) · [実行コマンドと検査](../REPRODUCE.ja.md)
